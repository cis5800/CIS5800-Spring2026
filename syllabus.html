Coding Homework

🖼️
Homework 1 — Image Transformations 10% of grade
Scaling · Translation · Rotation · Homography
Implement fundamental 2D image transformations using matrix operations. Includes both a written component and a programming component.
📄 PDF 📓 Notebook
📷
Homework 2 — AR Pose Estimation 10% of grade
Homography · PnP · Procrustes · P3P · RANSAC
Estimate camera pose from 2D–3D correspondences and overlay 3D models in augmented reality. Includes written and programming components.
📄 PDF 📓 Notebook
📸
Homework 3 — Stereo 3D Reconstruction 8% of grade
Epipolar Geometry · Disparity · Depth Estimation · Gradio UI
Compute stereo disparity maps and reconstruct 3D depth from a calibrated stereo pair. Results are visualized in an interactive Gradio web app.
📄 PDF 📓 Notebook
🎬
Homework 4 — Optical Flow & Epipole Estimation 8% of grade
Lucas-Kanade Optical Flow · Spatiotemporal Gradients · Epipole Estimation · SVD
Implement Lucas-Kanade optical flow on video frames and estimate the epipole from flow fields. Includes an interactive Gradio visualizer for any uploaded video.
📓 Notebook
